# Core 0.5.0 API migration

Core 0.5.0 retains all 22 export-map keys and reduces the published surface
from 373 to 342 named/entrypoint pairs. The [complete review](../development/0.5.0-public-api.md)
records a decision and supported consumer use for every name and path.
This document covers all 31 removed pairs and the removed `SSGOptions` generic.

| Previous owner                        | Removed names                                                                                           | Replacement                                                                                                                                     |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `@askrjs/askr/testing`                | `mount`                                                                                                 | `render(component, options)` with the same options, return value, and cleanup behavior                                                          |
| `@askrjs/askr/testing`                | `queryState`                                                                                            | `mockQuery(data, options)` for fresh data; `mockQuery.loading`, `.error`, `.refreshing`, `.stale`, and `.pendingWrite` for other fixture states |
| `@askrjs/askr/testing`                | `matchRoute`                                                                                            | Import `matchRoute` from `@askrjs/askr/router`; keep its arguments                                                                              |
| `@askrjs/askr/foundations/utilities`  | `ariaDisabled`, `ariaExpanded`, `ariaSelected`                                                          | Typed JSX attributes or an application-local props expression with the omission rules below                                                     |
| `@askrjs/askr/foundations/utilities`  | `DefaultPreventable`, `PropagationStoppable`, `FocusLikeEvent`, `KeyboardLikeEvent`, `PointerLikeEvent` | Native DOM event types for DOM callbacks, or a local structural event type for synthetic adapters                                               |
| `@askrjs/askr/foundations/state`      | `isControlled`, `resolveControllable`, `makeControllable`                                               | Local mode/value/setter logic; adopt render-owned `controllableState` only when its different behavior is intended                              |
| `@askrjs/askr/foundations/structures` | `createLayer`, `Layer`, `LayerOptions`, `LayerManager`                                                  | Supported UI overlay composition, or an explicitly application-owned bespoke stack                                                              |
| `@askrjs/askr/router`                 | `ParsedSegment`, `PageScopeRecord`, `LayoutScopeRecord`                                                 | Route authoring through `route`, `page`, `group`, and `RouteOptions`; `RouteRecord` member indexed-access types for diagnostics                 |
| `@askrjs/askr/router`                 | `AuthContext`, `AuthRequirement`                                                                        | Type imports from `@askrjs/auth`                                                                                                                |
| `@askrjs/askr/ssr`                    | `SSRRoute`                                                                                              | Router `Route` for custom context path/handler bindings; a `RouteRegistry` for request rendering                                                |
| `@askrjs/askr/ssg`                    | `RouteConfig`                                                                                           | Router `route`, `RouteOptions`, and `RouteRegistry`; pass `registry` to `SSGOptions`                                                            |
| `@askrjs/askr/ssg`                    | `DiscoveredResources`                                                                                   | For supported reporting use `SSGResult.routes` and each route's `resourceCount`; custom discovery maps are application-owned                    |

| `@askrjs/askr/jsx-dev-runtime`        | `JSXComponent`, `JSXElement`, `JSXElementType`                                                          | Type imports from `@askrjs/askr/jsx-runtime`                                                                                                    |

## Fixture aliases

Replace `mount` imports and calls with `render`. Replace
`queryState.fresh(data, options)` with `mockQuery(data, options)`, and change
other `queryState.member(...)` calls to `mockQuery.member(...)` with the same
arguments. `queryState` was a table, not a callable function; `mockQuery.fresh`
is not a replacement API.

```ts
import { mockQuery, render } from '@askrjs/askr/testing';
import { matchRoute } from '@askrjs/askr/router';

const user = mockQuery({ id: '123' });
const refreshingUser = mockQuery.refreshing({ id: '123' });
void [user, refreshingUser, render, matchRoute];
```

## Attribute and event shapes

Preserve omission explicitly: `ariaDisabled(false)` omitted the attribute,
while `ariaExpanded(false)` and `ariaSelected(false)` produced `"false"`.
Expanded and selected omitted the attribute only for `undefined`.

```tsx
function Trigger({
  disabled,
  expanded,
}: {
  disabled?: boolean;
  expanded?: boolean;
}) {
  return (
    <button
      aria-disabled={disabled ? 'true' : undefined}
      aria-expanded={
        expanded === undefined ? undefined : expanded ? 'true' : 'false'
      }
    >
      Open
    </button>
  );
}
```

Use `KeyboardEvent`, `PointerEvent`, and `FocusEvent` for native callbacks.
For synthetic adapters, declare the fields actually provided, such as
`Pick<Event, 'defaultPrevented' | 'preventDefault'>` or
`Pick<Event, 'stopPropagation'>`. Retained interaction helpers continue accepting
their structural event shapes; this removal does not require DOM-only events.

## Controlled state and layer stacks

Controlled mode is `value !== undefined`, including `null`, `false`, and zero
as controlled values. The old `resolveControllable(value, defaultValue)` was
equivalent to `{ value: value !== undefined ? value : defaultValue,
isControlled: value !== undefined }`.

The old `makeControllable` setter was stateless. In controlled mode it called
`onChange(next)`; in uncontrolled mode it called `setInternal(next)` before
`onChange(next)`. It did not suppress equal values. Preserve that ordering and
same-value behavior in local setter code when needed. `controllableState`
allocates render-owned state, returns a reactive getter/tuple, and suppresses
`Object.is`-equal writes, so adopting it is a deliberate state-model change.

The retired layer manager exposed manual registration and event dispatch.
Supported UI Dialog, Popover, and DismissableLayer composition own their
respective behavior; they are not drop-in `LayerManager` replacements.
Bespoke stacks must explicitly own registration/unregistration, teardown,
inside-root and portal detection, and Escape/outside-pointer dispatch.

## Router, SSR, and SSG records

Public route authoring uses a registry. Diagnostic consumers can still name
reachable record members as `RouteRecord['segments'][number]`,
`RouteRecord['pageChain'][number]`, and `RouteRecord['layoutChain'][number]`.
The optional Auth peer bridge remains: basic Core imports compile without
installing Auth, while applications that use Auth import its named types there.

Replace every `SSGOptions<...>` annotation with `SSGOptions`. The old parameter
was unused and did not permit route arrays or change generator inputs/results.
Internal route normalization and resource discovery are implementation details;
custom discovery-map data has no public generator input/output replacement.

```ts
import { createRouteRegistry, route } from '@askrjs/askr/router';
import { createStaticGen, type SSGOptions } from '@askrjs/askr/ssg';

const registry = createRouteRegistry(() => {
  route('/posts/{slug}', ({ slug }) => slug, {
    entries: async () => [{ slug: 'first-post' }],
  });
});
const options: SSGOptions = { registry, outputDir: './dist' };
const generator = createStaticGen(options);
void generator;
```

## JSX owners

Production transforms retain `jsx`, `jsxs`, `Fragment`, and the `JSX` namespace
at `jsx-runtime`. Development transforms retain `jsxDEV`, `Fragment`, and their
`JSX` namespace at `jsx-dev-runtime`. The root `createElement` factory remains
required for compiler fallback when a key follows a props spread. Manual JSX
annotation imports use the production runtime; ordinary TSX needs no import
changes for these moved annotations.
