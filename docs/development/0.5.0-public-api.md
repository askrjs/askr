# Core 0.5.0 public API review

This inventory records the Core 0.5.0 API decisions. Package qualification, final cross-package acceptance, and publication approval remain separate release gates.

Reviewed baseline Core: `8055a0420bef5045e242af6b2d03b8d5771381a8`; review source has identical tree `8ac57a9dd6cbea968a96b0883c42217fc0083673`.

All 373 named/path pairs reviewed: 342 KEEP, 23 REMOVE, 8 MOVE. All 22 export-map keys are retained. See the [migration guide](../migration/0.5.0.md) for every removed name and the non-generic SSGOptions change.

Every KEEP below states a concrete supported consumer use case. The review uses source, declarations, documentation, and named consumer searches across the AskrJS workspace. Absence of an import is not the decision rule.
