# 0.5.0 readiness review

Review date: 2026-10-09. This is a dated planning and evidence snapshot, not a release qualification certificate.

The initial organization inventory contained 24 repositories and 61 open issues. The existing 0.5.0 milestones contain 48 issues. The maintainer selected **existing milestone plus confirmed bugs**: include five additional confirmed CLI/Themes defects, for 53 issues in the working release scope. All five confirmed bugs, the Logos, Lucide, Monaco, telemetry and i18n hardening gates, and the SSR output, DOM node, host prop and query lifetime and route authoring refactors are now closed; 38 scoped issues remain, plus eight backlog requests. Keep eight newer feature/integration requests in the backlog. No existing milestone issue is deferred by this review.

**Readiness: blocked.** The API contraction, deeper hardening evidence, the remaining navigation boundary refactor, coverage baseline, packed consumer matrix, and exact-version qualification remain open. Every published package is still on 0.4.x. An existing test suite or issue title does not establish the required hardening outcome.

## Delivery order

1. All five confirmed defects are delivered: Themes PR #196 and CLI PR #170. Continue package API/hardening work with the same regression, packed-consumer and exact-head CI evidence.
2. Complete the export decisions in #745 and each package API issue: enumerate named/type exports and paths, record KEEP/REMOVE/MOVE with consumer evidence, and migrate sibling source, docs, CLI templates, generated starters, website documentation, and examples.
3. Run each package hardening probe under #747. Inspect assertions before adding adjacent cases. Record exact test commands/outcomes and keep a regression for every confirmed bug. Preserve the six core refactor tickets and #743 as release work; coordinate characterization tests to avoid duplicate coverage.
4. Run the migrated examples and generated SPA, SSR, SSG, API and MCP applications against the complete packed candidate set. Verify nested dependency resolution, isolation, failure output, hydration, and SSG metadata.
5. Prepare all 18 package manifests and lockfiles for 0.5.0, with dated changelogs and migration notes. Record release commits and tarball digests. Promote and publish only after the package and consumer gates are qualified, in the publication order below. Read back tags, npm artifacts and clean consumer installations.
